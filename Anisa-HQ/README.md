# Anisa HQ

Персональная AI-система: виртуальный офис с агентами (Аниса, Бруно, Давид, Щит, Тельга) и Telegram-бот.

- `index.html` — офис (карта, агенты, настройки персонажей, дела, конституция). Ответы агентов на странице работают внутри claude.ai; на GitHub Pages ответов не будет, нужен сервер с ключом API.
- `bot/` — Telegram-бот (Node.js 20.6+, без зависимостей). Запуск: `bot/start.bat`.
- `bot/CLAUDE.md` — Конституция агентов.

## Первая отправка в GitHub
Запустите `push.bat` (нужен установленный git и вход в GitHub). Если репозиторий не пустой и пуш отклонён:
`git pull origin main --allow-unrelated-histories`, затем `git push -u origin main`.

## Бруно и коммиты
Бруно коммитит в ветку `bruno-dev` и ведёт pull request, в `main` сливает владелец. Токен GitHub хранится только в `bot/.env` (в репозиторий не попадает).

## Что ещё в архиве
- `archive/` — прежние версии офиса и первый чат-прототип (для истории, в работе не нужны).
- Актуальная версия офиса — `index.html`.
