# Anisa Bot v0.2
Запуск: двойной клик start.bat (первый раз спросит токены). Папка на C:, не на сетевом Z:.

Команды в Telegram:
- обычный текст: поручение Анисе (она сама передаст Бруно, Давиду, Щиту, Тельге);
- переслать боту сообщение от человека: Щит оценит, важное уйдёт Анисе, она предложит ответ в Вашем стиле с кнопками;
- `/in Любимая: Ты скоро?` — то же самое вручную;
- `/audit` — проверка агентов Анисой; `/rules` — Конституция (файл CLAUDE.md); `/remember текст` — в память.

Опционально в .env: GEMINI_KEY, VIP=Любимая,Мама,Батя,Папа

GitHub (Бруно коммитит сам):
- заполните GITHUB_TOKEN и GITHUB_REPO в .env (см. .env.example), перезапустите бота;
- команда Анисе или Бруно в Telegram («Бруно, поправь …») -> он читает репозиторий, коммитит в ветку bruno-dev и пишет в pull request;
- чтобы закоммитить готовый файл: отправьте его боту документом с подписью `/commit сообщение`
  или `/commit путь/в/репозитории.html | сообщение`.
